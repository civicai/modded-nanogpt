## The conversation prompt

This is how a model that only continues documents can be made to "chat": it is given the start of a
transcript and writes the AI's next line. Give it its own button, labelled something like
"Conversation with an AI".

```
The following is a conversation between a human and an AI assistant.
Human: Hello AI friend.
AI: Hello, how can I help you today?
Human: I just want to chat. How are you doing?
AI:
```
